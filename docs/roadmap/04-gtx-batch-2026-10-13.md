Same two graphs open:

  `Saved …: 2 objects`. Check the dialog added `.dcscene` on Windows.
- Copy the `.dcscene` to the desktop, quit, `DualCEditor <desktop>\<name>.dcscene`. The
  scene shows as saved: pose, hidden object, colour, the edited parameter. **Is the image
  the same as before the save?**

  object reloads; opened from the desktop copy, nothing reloads.
